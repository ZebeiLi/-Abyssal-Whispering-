# 深蓝絮语 · Abyssal Whispers

一片可以呼吸、可以触碰的海底世界。

## 打开方式

直接用浏览器打开 `index.html` 即可（支持本地 `file://` 运行），无需安装依赖或启动服务器。

## 交互

- **移动鼠标 / 轻触水面**：唤醒浮游微光，鱼群会羞涩地散开。
- **点击画面**：泛起涟漪，释放一串上升的气泡与光尘。
- **靠近水母**：水母会轻轻避让并亮起；点击水母会得到回应。
- **靠近鲸鱼**：鲸影会慢慢发亮；点击它，会听见一声低鸣（需开启声音）。
- **光景**：右上角可切换「晨汐 / 月潮 / 星海」三套色彩，颜色会平滑过渡。
- **声音**：开启由 Web Audio 实时生成的海潮、和声与风铃，无需音频文件。
- **静心呼吸**：进入 4 秒吸气、2 秒屏息、6 秒呼气的引导练习；可随时按 `Esc` 退出。
- **潜入深海**：收起开篇文字，进入纯净的全屏漫游；点击左上角标识可回到开篇。
- **回到海洋**：呼吸练习结束。
